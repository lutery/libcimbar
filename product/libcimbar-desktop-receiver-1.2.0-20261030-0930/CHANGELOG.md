# 变更日志 — Cimbar 桌面接收器 1.2.0

> 对比版本：1.1.0（2026-10-27）→ 1.2.0（2026-10-30）
> 1.2.0 是一次**启动兼容迭代**：接收器现已支持 Windows PowerShell 5.1 环境启动；解码、协议与文件格式完全不变。

## ✨ 新增

- **Windows PowerShell 5.1 启动支持**：`launch.ps1` 兼容 Windows PowerShell 5.1 与 PowerShell 7 双引擎；中文/空格路径在 5.1 下输出不再乱码（控制台流固定 UTF-8）。
- **`launch.cmd` 自动回退**：双击 `launch.cmd` 时优先用 PowerShell 7，检测不到时自动回退到 Windows PowerShell 5.1，无需用户选择引擎。

## 🔧 改进

- **启动失败诊断更准确**：服务进程快速退出时，PowerShell 7 下打印真实退出码，Windows PowerShell 5.1 下明确提示「未知退出码」并保留 stderr 原文与诊断日志路径（引擎限制，如实降级）。
- **端口占用提示**：端口被占时以可读原因拒绝启动（exit 3），不触碰占用进程。

## 🐛 修复

- 修复：Windows PowerShell 5.1 下 CJK+空格路径的启动输出乱码问题。

## 📌 兼容性

- **运行时字节不变**：接收器 web 运行时（index/styles/src/worker/vendor/config 运行时部分）与 1.1.0 逐字节相同（27 个产品文件中 23 个不变）；仅启动链（launch.ps1、launch.cmd、package.json 版本号）与 asset-set 的 sourceRevision 戳变化。
- **升级零迁移**：覆盖解压即可用；无需迁移配置。

## 📌 已知限制与后续验收

- **现场验收待用户执行**：真实云桌面双输入等 7 项现场旅程（E2E-21～26、E2E-39）与真实后台行为（E2E-35）、辅助技术语音（E2E-37）需由用户在真实环境完成，1.2.0 包为其验收对象（与 1.1.0 相同的授权边界）。
- 以上缺口不影响本地验收结论：1.2.0 的启动链变更已按 round-16..20 五轮外部独立审查通过；运行时字节与 1.1.0 一致，1.1.0 已通过的全部本地证据按字节身份继续有效。
