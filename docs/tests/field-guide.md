# 现场操作手册 — 云桌面文件接收

目标：在真实 Citrix 云桌面环境里，用桌面接收端代替手机摄像头完成一次文件接收，
并把证据填进 `field-receipt.json`。

## 准备

1. 候选包（含 `DELIVERY-MANIFEST.txt` 的 `receiver/` 目录）已拷贝到本地某文件夹
   （路径可含中文与空格）。
2. 发送端就绪：云桌面里能显示 cimbar 动画的那个窗口（cimbar.org 或
   `cimbar_js.html` 打开并载入要传的文件）。
3. 已知文件在云桌面侧的 SHA-256（在云桌面内计算：`certutil -hashfile <文件> SHA256`）。

## 步骤

### 实时接收（E2E-21 / FAT-01）

1. 双击运行 `launch.ps1`（或 `pwsh -NoProfile -File launch.ps1`）。浏览器自动打开
   `http://127.0.0.1:8766/`。
2. 点击 **Share a window or screen**，在系统弹窗里选择云桌面客户端窗口。
3. 等待状态行出现 **File ready to save**（日志区会持续显示解码字节数）。
4. 点击 **Save file…**，在系统保存框里选目标位置。
5. 在本地对保存出的文件计算 `certutil -hashfile <文件> SHA256`。
6. 把两侧哈希、开始/结束时间、共享分辨率与帧率记入回执。

### 录像导入（E2E-22 / FAT-02）

1. 在云桌面侧把发送画面录制成视频文件（建议先试 30 秒）。
2. 回到接收页，点击 **Import a recording**，选择该录像。
3. 等待 Ready 后保存，计算两侧哈希并记入回执。

### 恢复与日常路径（E2E-23..25 / FAT-03..05）

按 `docs/tests/e2e-user-journey-plan.md` 的对应场景执行：取消选源重试、
传输中停止换文件、保存取消后重试与中文名/重名确认。

### 测量与回执（E2E-26 / FAT-06）

记录：共享分辨率、实际帧率（日志区每 30 帧提示一次）、开始/结束时间、
两侧 SHA-256、失败时的截图。回执里 **功能/性能/现场三列分开**：
阈值未冻结，性能只记测量值，不写 PASS。

## 边界与提示

- 只支持**模式 B**。发送端若用其他模式，日志不会有解码字节出现。
- 共享的窗口必须完整可见、不被缩放；RemoteFx/画质压缩由 Citrix 决定，
  本端不做任何图像调整。
- 若 5 秒仍无解码字节，日志会出现提示：检查窗口是否被遮挡或缩放。
- 服务只监听 `127.0.0.1`；端口被占用时用 `launch.ps1 -Port 8767`。

## 回执填写

`field-receipt.json`：每个场景一条记录，`result` 保持 `NOT_RUN` 直到真实执行；
执行后填 `executedBy: "user"`、两侧哈希、时间与截图引用。哈希不一致 → `FAIL`
并附复现材料；不要删除旧证据。
