## 四个独立门槛

1. **实施集成门**：54个必要单元用例和6集成组的适用子项均实际执行，目标存在且非0测试，未实现todo/skip不能计绿。C/WASM实际字节与fake策略分别报告。
2. **本地完整门**：E2E-1～20真实操作完成；双输入×两类文件各3轮hash一致、10轮生命周期和支持组合回归；实施方完成实际选源、导入、系统保存，不让用户代做。真实异常无法安全制造的分支由IAT覆盖并写明范围，不能免除正向/取消/停止/重试的真实操作。
3. **最终包门**：阶段6审查、7合并后，阶段8整套打包；E2E-20要求从最终包全新目录实际复验启动/实时/录像/保存取消重试，证据和字节摘要对应。staging只叫候选。
4. **现场门**：E2E-21～26用户真实客户端执行。未执行仍NOT_RUN；本地门通过只允许交付现场测试版本，不声明云桌面兼容或生产发布就绪。

每个文件往返PASS必须有最终磁盘文件与原文件的外部SHA-256一致、字节数、计时和真实证据。生命周期/预期拒绝用例无文件时hash可null，不能强迫其虚构文件hash。源/处理fps、分辨率/DPI/zoom、模式、压缩前后尺寸、profile和版本必须记录。

性能阈值未冻结仅报告measurement；V-001/002/003实测资料供确认，V-004现场独立。门禁不得把未评定性能、现场NOT_RUN或合成元数据QA自动改成PASS。执行命令见[实施计划](../plans/2026-10-18-desktop-receiver-implementation.md)CMD-01～10，当前尚未实现/运行。
